# 4. GRADING RULES
#####################################################################
Class definitions:
- REJECTION : always REJECTION, no confusion. Includes fully dark / black area above 30%. -> reject relay.
- DOUBLE KERNEL : two cashews stuck together -> reject relay. Detection default OFF; show box
  measurements live; I set the limits.
- UPW       : skin together with ANY other defect -> UPW; skin above 30% with no other defect -> UPW.
- PKW2      : 2 or more black/green spots across the full rotation.
- PKW1      : exactly ONE black/green spot across the full rotation (PKW2 wins if seen enough).
- OIL       : yellow with a green tint.
- BROWN     : looks brown. Light brown is decided by the CNN (taught with images), not a fixed threshold.
- DW2       : dirty and dark.   DW1 : dirty.
- TESTA     : skin only, 5-30%, no other defect.   TESTA SMALL : skin only, 1-5%, no other defect.
- WHITE_DW  : no defect, white, but shrivelled (old / dried).
- GOOD      : none of the above + NECK seen -> colour -> size grade -> grade relay.
- Undefined : low CNN confidence, class not mapped, no clear vote, not rolled, size outside every
  grade -> reject relay.

Priority (highest first), editable in UI:
  REJECTION = DOUBLE KERNEL = Undefined (reject relay)
  > UPW > PKW2 > PKW1 > OIL > BROWN > DW2 > DW1 > TESTA > TESTA SMALL > WHITE_DW > GOOD

Voting start values (from the 5-track machine): GOOD >= 3 views at >= 0.80; defect >= 0.50 in at
least 2 frames. All editable in UI. Use priority_rules (#22) for this.

For now skin %, dark %, spot count come from CNN votes. Tell me whether measuring skin area %,
dark area % and counting spots with image processing (inside the mask, across frames, without
counting the same spot twice) would be more reliable and what data you need.

GOOD -> colour -> size:
- Colour: SW (Scorched/Second White, slightly yellow) vs WW (premium white), decided by colour
  measurement inside the mask (median over frames, after colour gain/FFC), NOT by the CNN SW class.
  Propose the colour metric (e.g. LAB b*). SW/WW threshold: slider in UI with live value; I tune it
  with a teach helper on samples.
- Size: from the contour (length, width, area in mm via px_per_mm calibration, median/max over
